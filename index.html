Privacy Policy – Everything Extension

Last updated: November 21, 2026

About the Extension

Everything is a customizable new-tab extension with search, shortcuts, clock and wallpaper controls.

Data Storage

The extension uses browser storage to save user preferences, shortcuts and customization settings.

Search Suggestions

The extension uses Google Suggestions API to provide search suggestions. Search queries may be sent to Google to retrieve suggestions.

Data Sharing

We do not sell users' personal information.

Security

User settings are stored using the browser's storage functionality.

Contact

For questions about this privacy policy, contact the developer through the extension's store listing.
